plakd store — backup of the current SQLite stores

USAGE:
  plakd store backup <directory> [--budget-secs <seconds>]

Copy the runtime, product and agent-tree databases at a shared point in time.
Use a new directory outside PLAK_HOME under a parent you own. The private
backup directory contains the SQLite files and a SHA-256 manifest.
The live host can keep serving during the copy.

OPTIONS:
  --budget-secs <seconds>  Maximum seconds to spend copying before timing out
                           (default: 600; override with PLAK_STORE_BACKUP_BUDGET_SECS)
