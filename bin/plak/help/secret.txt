plak secret — named secrets for config.toml

USAGE:
  plak secret set <name>
  plak secret rm <name>
  plak secret list

  A name matches [a-z][a-z0-9-]{0,31}. config.toml refers to a secret by name
  ([mcp_servers.<id>] secret_env, bearer_secret, secret_headers), never by value.
  set reads the value from a hidden prompt, never from the command line.
  list prints names only. Values live in <home>/secrets/named/<name>.secret
  (mode 0600); there is no environment override.
