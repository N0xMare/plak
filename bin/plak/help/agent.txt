plak agent — long-lived JSONL host client

USAGE:
  plak agent [--account <codex|grok|claude|openrouter|openai|anthropic|xai-api> --model <exact-id> [options]]
  plak agent --session <uuid> [--resume-tree]

DESCRIPTION:
  Attaches the same plakous-hosted loop as the TUI and speaks newline-delimited
  JSON (v=1) on stdin/stdout. Stdio is the default pipe; there is no
  `plak agent stdio` subcommand.
  During turns, models still call topology tools in the catalog; JSONL
  invoke_tool is an idle-only host inject of the same grant-compiled
  executor (optional agent_id). JSONL fork maps to TUI /fork.

EXAMPLES:
  plak agent --account codex --model gpt-5.6-luna --effort medium
  plak agent --session 0f2c… --resume-tree
  printf '{"v":1,"kind":"prompt","id":"1","text":"hi"}\n' | plak agent --account grok --model grok-4.6 --effort low

OPTIONS:
  --account <id>     codex | grok | claude | openrouter | openai | anthropic | xai-api
                       (alias: --provider)
  --model <exact-id> Exact catalog model id
  --effort <level>   none | low | medium | high | xhigh | max | ultra
  --composition <c>  plakous-default | direct | native-ptc | js-ptc | py-ptc
                     (default: plakous-default, which follows the catalog)
  --protocol <p>     auto | chat | responses | messages (OpenRouter only;
                     default auto→chat; other accounts reject it at parse time)
  --session <uuid>   Attach that session; its recorded binding wins
  --resume-tree      Resume a RestoredPaused topology (requires --session)
  Omitted flags use the configured defaults. Binding flags match `plak run`.

COMMANDS (stdin):
  prompt, interrupt, compact, resume_queue, resume_tree, tree, interrupt_node,
  close_node, stop_all, clear, invoke_tool, fork, recover, background, quit

EVENTS (stdout):
  hello, ready, status, busy, assistant, assistant_done, tool, error,
  turn, tree, queue, bye

NOTES:
  Stdout is machine-only. Diagnostics go to stderr.
  RestoredPaused attach requires --resume-tree (same as plak run). Mid-session
  stdin resume_tree sends ResumeTopologyTree on an already-live hub.
  A restored queue stays paused until stdin resume_queue explicitly resumes it.
  --resume-tree on a session without a durable tree resumes the plain session.
  `--composition js-ptc|py-ptc` is one engine per agent; exec_js uses source
  (async module; text(...)), exec_py uses code. Same overlay as `plak run` on
  new sessions. native-ptc and js-ptc locate PLAK_JS_HOST or a sibling
  plakous-js-host; py-ptc locates PLAK_MONTY_WORKER or a sibling monty worker.
  A missing Code Mode sidecar fails closed.
