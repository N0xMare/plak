# plakous-tool-plan

The bounded task plan: a revisioned PlanState port, its replacement tool, and
the id-merge lowering. This crate is part of
[Plak](https://github.com/N0xMare/plak), an embeddable single-agent
multi-provider harness library (Plakous) and the command-line and terminal
product built on it. It is a published-internal package: it releases in the
exact version cohort of the `plakous` facade and carries no direct-use
compatibility or support promise, so embed through `plakous` instead.
Documentation and the specification live in the repository.
