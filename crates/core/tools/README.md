# plakous-tools

Portable tool contracts, registries, environments, and coding tools for Plakous.
This crate is part of [Plak](https://github.com/N0xMare/plak), an embeddable
single-agent multi-provider harness library (Plakous) and the command-line and
terminal product built on it. It is a supported Plakous package: its supported
inventory is the one its compile fixture in the repository names, and everything
else it exports is nameable, not supported. Documentation and the specification
live in the repository.
